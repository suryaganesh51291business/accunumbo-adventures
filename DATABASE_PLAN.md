# AccuNumbo Database Plan

## Current prototype tables
- users / profiles
- adventure progress
- task attempts
- feedback

## Future production modules
- roles: student, teacher, admin
- adventures and tasks
- XP and coin transactions
- badges and user badges
- classes and class members
- assignments
- analytics events

## Privacy
Collect only necessary data, explain why it is collected, provide appropriate consent/privacy controls, and implement applicable school/parental/child-data safeguards before collecting personal information from school-age learners.
