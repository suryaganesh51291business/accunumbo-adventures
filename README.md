Run locally:
1. Install Node.js 20+
2. Open this folder in a terminal
3. Run `npm install`
4. Copy `.env.example` to `.env` and set JWT_SECRET
5. Run `npm start`
6. Open http://localhost:3000

The 10-task Adventure 1 game can now call:
POST /api/attempts
POST /api/progress
and save results against the logged-in student.
